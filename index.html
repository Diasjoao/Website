De dados brutos a
decisões estratégicas

Nossa metodologia em 90 dias garante que você saia construindo pipelines robustos em produção, não apenas entendendo teoria.

1

Semanas 1–3: Fundação sólida

SQL avançado, Python para dados, ciclo de vida e arquiteturas modernas.

2

Semanas 4–6: Ingestão e armazenamento

Pipelines de batch e streaming, modelagem de Data Warehouse, Delta Lake.

3

Semanas 7–9: Processamento em escala

Apache Spark, PySpark, dbt, Airflow — tudo hands-on com dados reais.

4

Semanas 10–12: Cloud e qualidade

AWS/GCP/Azure, observabilidade de pipelines, Great Expectations.

5

Semanas 13–14: Portfólio e carreira

Projeto final completo, portfólio no GitHub e preparação para entrevistas.
